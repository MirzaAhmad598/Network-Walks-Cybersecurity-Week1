## 1. Project Overview

The objective of this project was to set up a practical cybersecurity testing lab environment using Oracle VirtualBox and Kali Linux.

This virtual environment provides a foundation for learning cybersecurity concepts and performing future ethical hacking and security testing exercises.

## 2. Tools and Technologies Used

- Oracle VirtualBox
- Kali Linux
- 7-Zip
- Virtual Machines
- NAT Network

## 3. Lab Configuration

| Component | Configuration |
|---|---|
| Virtualization Software | Oracle VirtualBox |
| Guest Operating System | Kali Linux |
| Network Mode | NAT Network |
| Network Subnet | 10.0.0.0/24 |
| Kali Linux IP Address | 10.0.0.2/24 |
| Clipboard Sharing | Enabled |
| Drag and Drop | Enabled |
| Shared Folder | /downloads |
| Internet Connectivity | Configured |
| VM Snapshot | Created |

## 4. Tasks Completed

1. Installed Oracle VirtualBox.
2. Downloaded and imported Kali Linux as a virtual machine.
3. Created a NAT Network using the 10.0.0.0/24 subnet.
4. Configured the Kali Linux IP address as 10.0.0.2/24.
5. Enabled clipboard sharing and drag-and-drop functionality.
6. Configured a shared folder between the host operating system and Kali Linux.
7. Configured network settings and internet connectivity.
8. Created a virtual machine snapshot for backup and recovery.
